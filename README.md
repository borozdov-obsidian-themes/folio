# Borozdov Folio

A theme from the Borozdov collection. Two faces — light **Afternoon**, a paper notebook in
warm daylight, and dark **Lamplight**, the same notebook at night. White cards on warm
paper, confident headlines, sticky-note callouts and one blue for action.

![Borozdov Folio in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/folio/main/screenshots/light.png)

![Borozdov Folio in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/folio/main/screenshots/dark.png)

## Principles

- **Warm paper, white cards.** The page is a warm off-white; code, tables and embeds sit
  on it as white cards with a hairline edge, never a shadow.
- **One blue.** Blue fills checked tasks, toggles and the main button, and colors links;
  every other button is a plain card.
- **Sticky notes.** Callouts are flat washes of their type's color; tags are marigold
  pills and highlights a marigold marker.
- **Confident headlines.** Inter at 600–700, tracked in tight as it grows; quotes switch
  to a book serif, like a pull-quote in a magazine.
- **Two shapes.** 12px cards, 8px controls; pills only for tags.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as sticky notes with no frame; the title in the type's color
- Code blocks as white cards; inline code in the notebook's coral
- Tables as white cards with a rounded hairline frame and grid
- Pull-quotes in Lyon Text, Source Serif or your platform's book serif
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colors meet WCAG contrast on both faces
- The phone layout keeps the same colors and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory, as a variant:** this theme ships inside **Borozdov
Ember**. Install Borozdov Ember under Settings → Appearance → Themes → Manage, then the
[Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, and choose
**Folio** under Style Settings → Borozdov Ember → Variant. The variant brings this theme's
palette, type and corners; its own layout, and its embedded font if it has one, come with
the full theme below.

**The full theme, by hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/folio/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Folio/`, then choose Borozdov Folio under
Settings → Appearance → Themes.
